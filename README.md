# Extra Mod Integrations

This mod is an addon for the powerful, new recipe viewer [EMI]. This addon adds support for viewing the listed mods'
recipes in EMI, including in the EMI Recipe Tree. This addon is still under construction and support for more mods is
planned!

[EMI]: https://modrinth.com/mod/emi

## Supported Mods

| Mod                         | Support | Notes                                                             |
|-----------------------------|:-------:|-------------------------------------------------------------------|
| Actually Additions          |    ✅    | NeoForge only, v1.0+ only                                         |
| Chipped                     |    ✅    | Fabric & NeoForge, v1.0+ only                                     |
| Farmer's Delight            |    ✅    | NeoForge only (Fabric version has native EMI support), v1.0+ only |
| Iron's Spells 'n Spellbooks |    ✅    | NeoForge only, v1.0+ only                                         |
| PneumaticCraft              |    ✅    | NeoForge only, v1.0+ only                                         |
| Rechiseled                  |    ✅    | Fabric & NeoForge, v1.0+ only                                     |
| Reliquary                   |    ✅    | NeoForge only, v1.0+ only                                         |
| Tech Reborn                 |    ✅    | Fabric only                                                       |

✅: Support Completed<br>
🚧: Support In Progress<br>
🔲: Support Planned<br>
⁇: Maybe Support Eventually<br>
❌: Not Supported<br>

[AE2 EMI Crafting]: https://modrinth.com/mod/ae2-emi-crafting
